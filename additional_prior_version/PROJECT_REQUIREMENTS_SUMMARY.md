# Capstone Requirements Summary

## Part 1 Data Analytics

Load the CSV into SQLite; analyse annual totals and holiday temperatures; calculate descriptive statistics, correlation, congestion probabilities, independence and an odds ratio; prepare a Power BI dashboard with daily, hourly, weather and temperature visuals, KPI cards and slicers; submit SQL/database, calculations, dashboard and a one-to-two-page insights report.

## Part 2 Python

Build a schema-first, exception-handled and fully logged cleaning pipeline; standardise categories, parse dates, remove exact duplicates and impute impossible sensor values; engineer time, cyclical, weather, scaled and quartile-based congestion features; save at least three Matplotlib figures with interpretations; provide a CLI with at least three queries; include scripts, figures, sample log, README and a one-to-two-page report. GitHub must show several descriptive commits.

## Part 3 Machine Learning and AI

Train and compare two algorithms for regression and two for proxy-risk classification; apply K-means and association rules; implement a neural network or other deep-learning approach plus SHAP/LIME explainability; apply an advanced technique such as MLflow; build a travel-time recommendation component; simulate model versioning, experiment tracking, API deployment, drift monitoring and PASS/ALERT reporting; include responsible-AI and final reports. Because no accident data exists, clearly label the high-risk target as a demonstration proxy.

## Manual submission items

A native Power BI `.pbix` dashboard must be assembled in Power BI Desktop using the supplied build guide. A GitHub repository must be created under the student's account and populated through genuine incremental commits; a fabricated commit history should not be submitted.
