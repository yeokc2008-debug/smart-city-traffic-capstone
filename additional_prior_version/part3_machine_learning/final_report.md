# Final Capstone Report

This project converts the I-94 traffic dataset into a reproducible traffic-intelligence prototype. Part 1 measures yearly, holiday, statistical, weather and congestion patterns and supplies SQLite queries plus Power BI preparation instructions. Part 2 cleans sensor anomalies, engineers time and weather features, saves four figures, logs every material action and exposes common questions through a CLI. Part 3 compares regression and proxy-risk classifiers, clusters traffic states, mines high-lift categorical patterns, trains a compact neural network, explains a comparable random-forest model with permutation importance, records experiments, recommends travel windows, serves a prediction endpoint and checks distribution drift.

The main operational insight is that time structure is more useful for traffic prediction than temperature alone. Recommendations should therefore prioritise hour and weekday/weekend patterns while using weather as context. Model scores and exact numeric findings are generated in `model_results.csv`, `cluster_profiles.csv`, `association_rules.csv` and the Part 1 output files so that the written conclusions remain reproducible.

The solution is a prototype. It covers a single corridor, the records are observational, missing holidays mean ordinary days, and no real accident outcomes exist. The proxy-risk classifier demonstrates workflow only. Real deployment requires multi-corridor validation, accident and travel-time data, temporal evaluation, human oversight, drift monitoring and documented rollback rules.
