Capstone Project: Smart City Traffic Intelligence: From Data Analytics to AI-Powered Mobility

Scenario
You are part of a Smart City Mobility Analytics Team supporting a city government in improving traffic management and commuter mobility.
The city has collected approximately 48,000 hourly records of westbound I-94 traffic volume near Minneapolis–St Paul, together with weather conditions and US federal holiday information. The dataset contains traffic volume, temperature, weather and time-related information that can be used to understand traffic patterns, identify congestion, build predictive models and develop AI-enabled mobility solutions.

The Challenge
Your team has been asked to transform this raw dataset into an end-to-end traffic intelligence solution.
The project is divided into three connected parts:
1.	Part 1 – Data Analytics: Explore, analyse and communicate historical traffic patterns using SQL, statistics, probability and Power BI. 
2.	Part 2 – Python: Build a reproducible Python data pipeline, engineer features, visualise patterns and create a small analytics application. 
3.	Part 3 – Machine Learning: Develop predictive and analytical AI models, explain their outputs, simulate deployment and monitoring, and translate the results into actionable mobility recommendations.
Each part should build on the previous one. Reuse and extend the cleaned data, engineered features and analytical findings wherever appropriate.

Note Before You Start: Missing Accident Dataset
Some of the tasks in this part refer to an accident dataset. However, no accident dataset has been provided for this capstone.
To enable you to complete the classification task, you will create a proxy accident-risk label from the available data. This proxy is intended only to demonstrate the machine learning classification workflow and should not be interpreted as a prediction of actual accidents.

First, create a congestion category based on the quartiles of traffic_volume:
# Congestion category (data-driven quartiles of traffic_volume)
q1, q2, q3 = df["traffic_volume"].quantile([0.25, 0.5, 0.75]).values

def bucket(v):
    if v <= q1:
        return "Low"
    elif v <= q2:
        return "Medium"
    elif v <= q3:
        return "High"
    return "Severe"

df["congestion_category"] = df["traffic_volume"].apply(bucket)

 

Then, create the proxy accident-risk label. A record is classified as high risk when high/severe congestion occurs together with severe or low-visibility weather conditions:
# Proxy accident-risk label
# High risk = severe/low-visibility weather conditions occurring
# together with High/Severe congestion.

high_congestion = df["congestion_category"].isin(["High", "Severe"])

risky_weather = (
    df["weather_main"].isin(SEVERE_WEATHER)
    | (df["is_low_visibility"] == 1)
)

df["high_risk"] = (high_congestion & risky_weather).astype(int)
